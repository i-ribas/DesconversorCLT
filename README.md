## Eu tenho a solução para você!
Aqui está um pequeno programa de Python que automatiza o processo de atualização e distribuição da Tradução PT-BR feita pela CLT District!

Esse programinha:
- Recebe o Token da sua conta do Paratranz
- Usa ele para fazer chamadas à [API do Paratranz](https://paratranz.cn/docs) e baixar a versão mais recente
- Instala ele na sua pasta do Limbus
- E também forma uma pastinha zip pra você passar uma versão beta, ou uma versão para distribuir para o público!

## Como Usar
Só baixar o .exe e mandar bala! De simples uso e eficiente pra não ficar matando tempo.
(Lembrando, isso é específico para os Gerentes do Projeto de Tradução do Limbus Company, que usam a plataforma do ParaTranz!)
